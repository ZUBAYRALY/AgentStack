## 🌟 What is AgentStack?

**AgentStack** turns standard AI coding assistants into an elite **Principal Full-Stack Architect + Staff Frontend Lead + Technical SEO Specialist + Security Auditor** working synchronously in your workspace.

Instead of generic prompts, chaotic outputs, or hallucinated fake data, AgentStack establishes **strict, non-negotiable engineering protocols**, **persistent self-healing memory**, and **automated multi-disciplinary skills**.

---

## ✨ Supercharged Pillars

### 1. 🚦 Two-Stage Gated Onboarding (`/project`)
- **Stage 1 (Brainstorming Sandbox)**: Discuss ideas, refine feature specs, and choose tech stacks in `project.md`. The AI is strictly banned from generating premature code or touching core files.
- **Stage 2 (Kickoff Trigger)**: Upon explicit user confirmation, specs are automatically propagated across `PRD.md`, `Architecture.md`, `Phases.md`, and `Memory.md` to begin Phase 1 execution.
- **Existing Project Adoption**: Drop `.agent` into any existing codebase and run `/project` — the AI autonomously audits your repo, detects tech stack, enumerates routes, and syncs all tracking files.

### 2. 🎯 UI/UX Design Intelligence (`ui-ux-pro-max`)
- Integrated with [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).
- **67+ UI Styles** (Minimal, Clean Dark, Glassmorphism, Brutalism).
- **96+ Accessible Color Palettes** with contrast ratios.
- **57+ Google Font Pairings** tailored by industry niche.
- **Anti-Patterns & Pre-Delivery Checklist**: Prevents generic purple gradients and clunky layouts.

### 3. 🪄 Tactile Spring Micro-Interactions (`motion`)
- Powered by [motiondivision/motion](https://github.com/motiondivision/motion) (`motion/react`).
- **Tactile Feedback**: Spring physics on all clickables (`whileHover={{ scale: 1.02 }}`, `whileTap={{ scale: 0.98 }}`).
- **Smooth Exits**: Seamless modal, drawer, and toast enter/exit handling with `<AnimatePresence>`.
- **Sliding Indicators**: Effortless active tab and pill highlights via `layoutId`.
- **120fps GPU Performance**: Strictly animates composite properties with `prefers-reduced-motion` compliance.

### 4. 🔍 Universal Technical SEO & AEO (`claude-seo`)
- Powered by [AgriciDaniel/claude-seo](https://github.com/AgricIDaniel/claude-seo).
- **24 Specialized Sub-Skills**: Technical audits, Schema.org JSON-LD generation, Core Web Vitals optimization, OpenGraph cards, sitemaps, and GEO/AEO (AI Overviews/ChatGPT search discovery).
- Enforces strict semantic HTML (`<main>`, single `<h1>`, sequential headings) automatically during page construction.

### 5. 🛡️ Military-Grade Defensive Security
- **OWASP Top 10 by Design**: 100% Parameterized ORM queries (zero raw SQL injection).
- **XSS Sanitization**: Prohibits raw `dangerouslySetInnerHTML`.
- **Tenant & Workspace Scoping**: Server-enforced multi-tenancy on all database lookups.
- **HTTP Hardening**: Helmet CSP, rate-limiting, and SSRF private IP blocking.

### 6. 🧠 Immortal Persistent Memory & Audit Trail
- **[Memory.md](.agent/workflows/Memory.md)**: Real-time system state and active development focus.
- **[done.md](.agent/workflows/done.md)**: Immutable, cumulative audit log of all completed endpoints, models, and UI views.
- **[Phases.md](.agent/workflows/Phases.md)**: 7-Phase build order checklist automatically checked off on task completion.

## 🚀 Quick Start

### Installation

1. **Clone or Download**:
   ```bash
   git clone https://github.com/zubayraly/AgentStack.git
   ```

2. **Drop into Any Project**:
   Copy the `.agent/` folder directly into the root of your project:
   ```bash
   cp -r .agent /path/to/your-project/
   ```

3. **Launch Your Coding Agent**:
   Open the project in **Antigravity IDE**, **Claude Code**, or **Cursor**.

### Starting a New Project
Simply type in your chat:
```bash
/project
```
> The agent enters **Stage 1 Brainstorming Mode** to refine your concept, choose the tech stack, and finalize the spec in `project.md`. When you're ready, say: *"Specs finalized, start implementation!"*

### Adopting an Existing Project
Paste `.agent` into your existing project and prompt:
> *"Audit this existing project and adopt AgentStack workflow."*
The agent scans your codebase, maps out all active routes/models, updates all workflow documents, and positions you at the exact current phase!
